# Mood Playlist Picker

Pick how you're feeling and get a Spotify playlist to match. Built with HTML, CSS, and JavaScript.

## Features
- 6 moods, each linked to an official Spotify playlist
- Playlist plays right inside the page (Spotify embed)
- "Surprise me" button for a random mood
- Remembers your last mood
- Cute pastel design that works on mobile

## Usage
Open `index.html` in your browser (internet needed). Log in to Spotify in the same browser to play full songs; otherwise you get 30-second previews.
